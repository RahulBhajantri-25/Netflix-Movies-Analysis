# 🎬 Netflix Movies Analysis

## 📌 About the Project

This project explores a Netflix movies dataset using Python to understand patterns and trends across movies, including their **genres, release years, and ratings**.

The main goal of the project was to take a raw dataset, clean and prepare the data, perform exploratory data analysis (EDA), and use visualizations to identify meaningful patterns.

This project helped me gain practical experience in working with a real-world dataset and applying the different stages of a data analysis workflow.

---

## 🛠️ Tools & Technologies

* **Python**
* **Pandas**
* **NumPy**
* **Matplotlib**
* **Jupyter Notebook**

---

## 🔍 What I Worked On

As part of the analysis, I:

* Explored the structure and characteristics of the dataset
* Checked for duplicate records and missing values
* Cleaned and prepared the data for analysis
* Converted release dates into the appropriate date format
* Extracted the release year from the release date
* Removed unnecessary columns
* Categorized movie ratings
* Analyzed movie genres
* Split multiple genres and transformed them into individual entries
* Examined the distribution of movies across release years
* Created visualizations to better understand the data

---

## 📊 Key Finding

One of the key findings from the analysis was that **Drama was the most frequently occurring genre** in the dataset.

The analysis also provided an overview of how movies were distributed across different release years and rating categories.
